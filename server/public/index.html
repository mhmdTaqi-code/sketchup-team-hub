        المشاريع

          عنوان السيرفر للفريق

          كل عضو يكتب واحد من هذي العناوين داخل البلكن بـ SketchUp. للربط عن بعد استخدم عنوان Radmin VPN (يبدي عادةً بـ 26.).

            البلكن

            نفس البلكن لكل الفريق، شنو ما جانت نسخة SketchUp. العضو ينزله من هنا، أو من الرابط /download/su_team_hub.rbz على عنوان السيرفر.

            خطوات ربط عضو جديد

            1. ينصب Radmin VPN ويدخل نفس الشبكة (Join Network) باسمها وكلمة سرها.
            2. ينزل البلكن من فوك وينصب su_team_hub.rbz من SketchUp ← Extensions ← Extension Manager ← Install Extension.
            3. يفتح Extensions ← Team Hub ← لوحة الفريق، ويكتب عنوان السيرفر واسم المستخدم وكلمة السر.
            4. يختار المشروع ويدوس «تحميل المشروع».
