# SketchUp Team Hub

**Work on one SketchUp model as a team, at the same time.** One PC runs a small server; every teammate's SketchUp connects to it (over Radmin VPN or a local network). Share any .skp once; teammates download it and from then on every change reaches everyone within a second or two. Every version is kept.

- Edit anything, any time — optional reservations when you want something to yourself
- Automatic live sync — no "save and send"
- Full history with one-click rollback, from a web dashboard
- Works across SketchUp **2022 → 2026** in the same project
- Team chat, presence, who-is-editing-what
- Arabic (Iraqi) interface

> 📘 الدليل الكامل بالعربي تحت 👇 · Revit version: [revit-team-hub](https://github.com/mhmdTaqi-code/revit-team-hub)

## شنو هذا؟

نظام يخلي كل الفريق يشتغل على **نفس موديل SketchUp بنفس الوقت**:

```
 SketchUp (انت)  ─┐
 SketchUp (علي)  ─┼── Radmin VPN ──►  جهاز السيرفر: Team Hub Server ──► النسخة الرئيسية + كل التعديلات القديمة
 SketchUp (سارة) ─┘
```

- **احجز وعدّل:** تحجز العنصر (Group أو Component) وتعدل عليه، والتعديل يوصل للكل خلال ثانية أو ثنتين.
- **ما أكو تصادم:** العناصر المحجوزة من غيرك تكون مقفولة عندك، وحولها مربع ملوّن عليه اسم العضو اللي حاجزها.
- **أرشيف كامل:** كل نسخة من كل عنصر تنحفظ، وتكدر ترجع لأي نسخة من لوحة التحكم.
- **إصدارات مختلفة:** يشتغل بين نسخ SketchUp من 2022 لـ 2026. الملفات تنتقل بصيغة 2021 المشتركة بين كل هذي النسخ.

## الخطوة 1: نصّب Node.js (جهاز السيرفر بس)

1. روح لـ [nodejs.org](https://nodejs.org) ونزّل **LTS** لويندوز (ملف `.msi`).
2. شغّله ودوس **Next** لحد ما يخلص. الإعدادات الافتراضية تكفي.
3. تأكد إنه انصب: افتح **Command Prompt** واكتب:
   ```bash
   node -v
   ```
   لازم يطلع رقم مثل `v24.x.x` أو `v22.13` أو أحدث.

## الخطوة 2: نزّل المشروع وشغّل السيرفر

1. من فوك بهذي الصفحة: **Code ← Download ZIP**، وفك الضغط بأي مكان، مثلاً سطح المكتب.
   أو إذا عندك git:
   ```bash
   git clone https://github.com/mhmdTaqi-code/sketchup-team-hub.git
   ```
2. دبل كلك على **`start-server.bat`**.
   - أول مرة ينصب مكتبة وحدة (`ws`) وحده، يحتاج إنترنت.
   - **خلي هذي النافذة مفتوحة** طول ما الفريق يشتغل.
3. ويندوز راح يسألك عن **الجدار الناري (Firewall)** لـ Node.js. دوس **Allow access**، وفعّل **Private و Public** كلهن، لأن شبكة Radmin أحياناً تنحسب Public.
4. افتح بالمتصفح **http://localhost:8787** وسوّي **حساب المدير**.
5. من تبويب **الفريق** أضف حساب لكل عضو:

   | الصلاحية | شنو تكدر تسوي |
   |---|---|
   | **مصمم** | يحجز ويعدل |
   | **مشاهد** | يشوف بس |
   | **مدير** | يدير الفريق والمشاريع، ويفك الحجوزات، ويرجع أي عنصر لنسخة قديمة |

## الخطوة 3: Radmin VPN (حتى الفريق يتصل من أي مكان)

1. كل واحد ينزل وينصب Radmin VPN من [radmin-vpn.com](https://www.radmin-vpn.com). مجاني.
2. **صاحب السيرفر:** Network ← **Create Network**. يختار اسم للشبكة وكلمة سر، ويرسلهن للفريق.
3. **الباقين:** Network ← **Join Network**. يكتبون نفس الاسم وكلمة السر.
4. عنوان السيرفر على Radmin يبدي بـ **`26.`**. تلكاه بنافذة Radmin جنب اسم جهازك، وكذلك بلوحة التحكم ← **طريقة الربط**.
   هذا العنوان تنطيه للفريق: **`http://26.x.x.x:8787`**

## الخطوة 4: نصّب البلكن (كل عضو)

1. نزّل `su_team_hub.rbz`، إما من صفحة [Releases](../../releases)، أو من `http://26.x.x.x:8787/download/su_team_hub.rbz`.
2. SketchUp ← **Extensions ← Extension Manager ← Install Extension** ← اختار الملف.
3. يطلع شريط أدوات **Team Hub** وقائمة **Extensions ← Team Hub**.
4. افتح **لوحة الفريق**، واكتب عنوان السيرفر واسم المستخدم وكلمة السر.

## الخطوة 5: شارك ملف ويا الفريق

1. افتح **أي ملف** بـ SketchUp ← لوحة الفريق ← **«⇪ مشاركة هذا الملف ويا الفريق»**.
   - البلكن يرفع الملف كامل مرة وحدة.
   - كل ملف تشاركه يصير مشروع مستقل.
   - أي عضو يكدر يشارك، مو بس المدير.
2. **باقي الفريق:** لوحة الفريق ← **«الملفات المشتركة»** ← **«⇩ تحميل الملف المشترك»**.
   الملف ينزل وينفتح ويتصل وحده.
   أو ينزلونه من لوحة التحكم بالمتصفح، ويفتحونه بـ SketchUp، ويتصل وحده هم.
3. **من هنا وطالع:** بس التعديلات تنتقل، مو الملف كامل.

## الجديد بنسخة 2.1

- **ولا تحديث يضيع:** إذا صار خطأ بتطبيق أي تعديل، البلكن يرجّعه، ويعيد المحاولة، وبعدها ينزّل نسخة جديدة من السيرفر.
  قبل جان خطأ واحد يوكف المزامنة كلها.
- **إحداثيات الكومبوننت مضبوطة** حتى لو صاحبك يعدّل وهو داخل الكومبوننت.
- **الإصلاح الذاتي صار يشمل الأشياء الناقصة:** إذا عنصر موجود بالسيرفر ومو موجود عندك، ينزل وحده.
  وإذا انمسح بالسيرفر، ينمسح عندك.
- **البلكن ما يطلعك من الـ Group أو الكومبوننت** اللي داخله حتى يقرا أو يطبق تحديث.
- **الاختبار (نافذتين SketchUp حقيقيات):** 13 فحص، وكلهن نجحن مرتين ورا بعض.
- **2.1.1 (سرعة):** 2.1.0 جان يفحص كل خط بالموديل كل 3 ثواني، فالموديلات الكبيرة جانت تعلك («Not Responding»).
  هسه الفحص الدوري خفيف وله وقت محدد. على موديل بي 72,000 عنصر و30,000 خط، الفحص الكامل ياخذ 0.07 – 0.11 ثانية.
- **2.1.2 (كرش):** 2.1.1 جان يجبر SketchUp يعيد حساب صناديق الكومبوننتات كل 3 ثواني، وهذا جان يكرّش SketchUp إذا صادف وانت تحرك أو تسحب شي.
  هسه البلكن بس يقرا الإحداثيات من العناصر نفسها.
  وإذا SketchUp سكر فجأة، بالتشغيل الجاي السجل يكتب البلكن جان دا يسوي شنو بوقتها، أو إنه ما جان دا يسوي شي.

## الشغل اليومي (نسخة 2.0: ثبات قبل كل شي)

- **اللي تحدده أو تفتحه يصير إلك لحد ما تخلص (✎):** يتقفل عند الباقين بنفس اللحظة (أقل من 0.1 ثانية)، فمحد يعدل على نفس الشي وياك.
  هذا اللي يمنع الأشكال تنمسح أو تتكرر. من تطلع منه، يرجع مفتوح للكل خلال ثواني.
- **أي تعديل ينتقل كامل:** الـ Group أو تعريف الـ Component أو الخطوط السائبة.
  وياه بصمة لمحتواه (sighash) وصندوق إحداثياته (x, y, z).
- **الطرف الثاني يتأكد:** بعد كل تحديث يقارن المحتوى والمكان ويا اللي انرسل.
  إذا لكى أي فرق، يرجع ينزّل النسخة الصح وحده (self-healing).
- **الخطوط والسطوح السائبة** تتزامن بنفس إحداثياتها بالضبط.
  إذا اثنين رسموا بنفس اللحظة، رسمة الثاني تصير Group باسمه، **وما تنمسح**.
- **الكومبوننت:** التعديل داخله يوصل لكل نسخه، وكل نسخة تبقى بمكانها.
- **الحجز اختياري:** «حجز المحدد» يخلي الشي إلك لحد ما تفكه انت.
- **📶 البنك** مالك ومال كل عضو يبين بلوحة الفريق، وحالة الاتصال «⚡ لايف · WebSocket».
- **إرسال السجل:** إذا صار أي شي غلط، دوس «إرسال السجل» باللوحة. السجل يوصل للسيرفر (`server/data/logs`) حتى نعرف شنو صار.

> من 2.0، السيرفر يرفض التعديلات من البلكنات الأقدم. كل الفريق لازم يحدّث.

## الاتصال

اتصال **WebSocket** مفتوح دائماً ويا السيرفر.
إذا انقطع، البلكن يرجع للطريقة الاحتياطية (long-polling) وحده، ويرجع يجرب الـ WebSocket كل كم ثانية.

## شلون انجرب

بنافذتين SketchUp حقيقيتين، والفحص كل 50 ms. بالنهاية تنقارن **بصمة الموديل كامل**: كل عنصر، ومكانه، ومحتواه، والخطوط السائبة.
الاختبار انعاد 4 مرات، و**كل الفحوصات نجحت** بآخر مرتين ورا بعض:

| الاختبار | النتيجة |
|---|---|
| تقسيم سطح سايب يوصل للثاني بنفس الإحداثيات | ✅ 0.27 – 0.35 ثانية |
| فتح Group يقفله عند الثاني، والثاني ما يكدر يدخله | ✅ 0.03 – 0.07 ثانية |
| اثنين يرسمون بنفس الوقت، كل واحد داخل Group | ✅ |
| رسم داخل Component يوصل لكل نسخه | ✅ 0.15 – 0.20 ثانية |
| نسخ الـ Component تبقى بمكانها | ✅ |
| نسخ Group يوصل مرة وحدة بالضبط | ✅ 0.18 – 0.23 ثانية |
| مسح النسخة يوصل للأول | ✅ 0.07 – 0.14 ثانية |
| خطين سايبين بنفس اللحظة، ولا واحد ينمسح | ✅ |
| **الموديل كامل نفسه بالضبط عند الاثنين** | ✅ |

**ملاحظة:** هذا على جهاز واحد. عن بعد، كل رقم يزيد بمقدار البنك بينكم.

## حل المشاكل

| المشكلة | الحل |
|---|---|
| «ما كدرت أوصل للسيرفر» | تأكد إن `start-server.bat` شغال، وإن Radmin متصل (أخضر)، وإن العنوان والبورت `8787` صح، وإن Firewall مسموح لـ Node.js |
| `node` مو معروف | ما انصب Node.js، أو تحتاج تعيد تشغيل الجهاز بعد التنصيب |
| العنصر مقفول | احجزه أول. إذا محجوز من غيرك، اسمه مكتوب عليه |
| «غير متصل» | تعديلاتك محفوظة عندك وترتفع من يرجع الاتصال |
| «حدّث البلكن» (426) | من لوحة الفريق دوس **تحديث** وأعد فتح SketchUp |
| شي مو مضبوط | من اللوحة دوس **مزامنة كاملة**، وبعدها **إرسال السجل** |

## النسخ الاحتياطي

كل المشروع، مع كل النسخ القديمة، موجود بفولدر **`server/data/`**. انسخه بشكل دوري لهارد خارجي أو Google Drive، والأفضل والسيرفر مطفي.

## تحديث البلكن (للمطورين)

1. عدّل الكود بـ `plugin/`، وارفع `PLUGIN_VERSION` بملف `plugin/su_team_hub.rb`.
2. شغّل:
   ```bash
   node tools/build-plugin.js
   ```
   هذا يطلّع `dist/su_team_hub.rbz`، وينشر النسخة على السيرفر.
3. كل عضو يطلعله زر **تحديث** بلوحة الفريق.

## هيكل المشروع

```
plugin/             البلكن (Ruby): المزامنة، الحجز، اللوحة، الرسم بالشاشة
  su_team_hub/session.rb   محرك المزامنة
server/             السيرفر (Node.js + SQLite + WebSocket) ولوحة التحكم
tools/              بناء ملف .rbz
start-server.bat    تشغيل السيرفر
```

نفس السيرفر يخدم مشاريع Revit هم. شوف [revit-team-hub](https://github.com/mhmdTaqi-code/revit-team-hub).
